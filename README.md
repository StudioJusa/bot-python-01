**Tecnologias utilizadas:** Python, automação de interface e manipulação de dados.

**Origem do projeto:** Desenvolvido durante o curso **Jornada Python**, da **Hashtag Programação**.

### Contexto do Projeto

O cadastro manual de produtos em sistemas administrativos pode ser um processo repetitivo, demorado e sujeito a erros de digitação. Em empresas que lidam com grandes volumes de produtos, essa tarefa pode consumir muito tempo operacional.

Neste projeto, o objetivo foi desenvolver uma **automação capaz de realizar o cadastro de produtos de forma automática em um sistema web**, simulando as ações de um usuário.

### Solução Desenvolvida

Utilizando **Python**, desenvolvi um script que atua como um **robô de automação**, responsável por executar todo o processo de cadastro de produtos.

O fluxo automatizado inclui:

- Abertura do sistema no navegador
- Realização de **login automático**
- Acesso à página de **cadastro de produtos**
- Preenchimento automático dos campos do formulário
- Envio das informações para registrar cada produto no sistema

O script percorre uma base de dados contendo as informações dos produtos e repete o processo de preenchimento para cada registro, permitindo o cadastro em escala sem intervenção manual.

### Resultados

A automação permite:

- Reduzir significativamente o tempo gasto no cadastro manual
- Minimizar erros humanos durante o preenchimento
- Padronizar o processo de inserção de dados no sistema

Este projeto demonstra como **Python pode ser aplicado para automação de tarefas operacionais**, aumentando a produtividade e otimizando processos repetitivos em sistemas administrativos.
